# Data folder

- `benchmark-facts.json` contains current client-provided benchmark facts and unresolved definitions in machine-readable form.
- `country-market-master.csv` provides a worldwide ISO country/territory registry and research slots. Only evidence-backed starter signals are populated. `research_pending` is intentional.
- `language-market-seeds.csv` is a research queue for language-first and diaspora-market discovery. Speaker percentages and counts are intentionally blank until sourced with consistent definitions.

Do not interpret blank numeric cells as zero. Do not turn the research queue into production estimates until each row has source provenance and review.
