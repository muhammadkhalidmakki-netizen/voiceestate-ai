# Data folder

- `benchmark-facts.json` contains current client-provided benchmark facts and unresolved definitions in machine-readable form.
- `country-market-master.csv` provides a worldwide ISO country/territory registry and research slots. Only evidence-backed starter signals are populated. `research_pending` is intentional.
- `language-market-seeds.csv` is a research queue for language-first and diaspora-market discovery. Speaker percentages and counts are intentionally blank until sourced with consistent definitions.

## How to change a CPL

Edit **`country-cpl-estimates.csv`** directly: change `cpl_low_aed`, `cpl_base_aed` and `cpl_high_aed` on the country's row (leave `cpl_low_aed` empty for a "30 or less" style ceiling), and save. Close the file in Excel before the update runs.

Then either:
- double-click **`update-market-data.cmd`** in the project folder (or run `npm run intel`), or
- leave **`watch-market-data.cmd`** open (or `npm run intel:watch`): it updates by itself every time you save `country-cpl-estimates.csv`, `benchmark-facts.json` or `market-scoring-config.json`.

Then refresh the dashboard.

- **Your edits are kept.** The update remembers what it wrote last time. A row whose numbers you changed is marked `user_override`, used exactly as typed (no 20% safety margin) and shown as "your benchmark". It survives every later update.
- **Rows you did not touch** are refreshed from the model and your client benchmarks as before.
- **To undo an edit**, clear the three CPL cells on that row and update: the row goes back to the client benchmark or the model value.
- **A bad edit** (low above high, base outside the range, text instead of a number) is ignored with a message and the row is restored.
- Other generated CSV files are still overwritten on every update; only `country-cpl-estimates.csv` keeps your edits.

## Market-intelligence datasets (added 2026-11-06)

Generated by `python scripts/market-intel/build_datasets.py` from open sources (World Bank, Unicode CLDR, Eurostat) plus the client files above, which are never overwritten. The build also refreshes the compact JSON in `src/lib/market-planning/data/intel/`.

- `country-market-signals.csv`, `country-cpl-estimates.csv`, `country-advertising-cost-signals.csv`, `country-keyword-demand.csv` (header only: no Keyword Planner access)
- `language-master.csv`, `country-language-distribution.csv`, `diaspora-market-opportunities.csv`
- `research-source-register.csv`, `data-coverage-report.json`, `market-scoring-config.json`
- `client-cpl-input-template.csv` for adding real campaign results
- `country-investment-conditions.csv`, `dubai-survey-evidence.csv`, `country-buyer-motivations.csv`
- `investment-intelligence-methodology.md`, `cpl-estimation-methodology.md`, `language-data-methodology.md`, `dynamic-recommendation-methodology.md`, `research-limitations.md`

Check with `node scripts/market-intel/validate.mjs`. Print sample recommendations with `node scripts/market-intel/sample-recommendations.mjs` and rankings or a country comparison with `node scripts/market-intel/report-rankings.mjs GB SD`.
`country-market-master.csv` keeps every client column; only the status, source and date columns were updated.

Do not interpret blank numeric cells as zero. Do not turn the research queue into production estimates until each row has source provenance and review.
